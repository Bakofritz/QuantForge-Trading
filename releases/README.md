# QuantForge Release Archive

This directory contains human-readable records for QuantForge build iterations.

## Stable records

Confirmed stable iterations are recorded in their release directories, including:
- v26.46
- v26.47

## Failed records

Failed iterations are cataloged separately under `releases/failed/` and in `releases/FAILED_ITERATIONS.md`. Failed builds are historical evidence only and are never represented as stable releases.

## Correction work

A correction iteration remains a candidate until its native build and tests pass. The correction does not inherit stable status merely because it fixes a known failure.

Source code remains in the normal repository tree; Git commits and branches preserve the exact source state for every iteration.
